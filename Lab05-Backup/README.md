# Lab 05 - Azure Backup and Recovery

## Objective

Explore Azure Backup and Recovery services using Recovery Services Vault.

## Services Used

- Azure Resource Group
- Recovery Services Vault
- Backup Policies
- Azure Backup Center

## Tasks Performed

1. Created Resource Group (RG-AZ104-LAB05)
2. Created Recovery Services Vault (RSV-AZ104-LAB05)
3. Reviewed Backup Storage Redundancy settings
4. Explored Backup Policies
5. Explored Backup Center
6. Reviewed Backup Items and Protected Resources

## Skills Learned

- Recovery Services Vault
- Backup Policies
- Backup Management
- Protected Resources
- Disaster Recovery Concepts
- Business Continuity Concepts

## Outcome

Successfully explored Azure Backup and Recovery capabilities and understood how Azure protects resources using Recovery Services Vault.
