# Lab 04 - Azure Storage and SAS Token

## Objective

Learn to securely share Azure Storage blobs using Shared Access Signatures (SAS).

## Services Used

- Azure Resource Group
- Azure Storage Account
- Blob Container
- Shared Access Signature (SAS)

## Tasks Performed

1. Created Resource Group (RG-AZ104-LAB04)
2. Created Storage Account (staz104storage01)
3. Created a Private Blob Container
4. Uploaded a text file
5. Generated a SAS Token
6. Accessed the file using a SAS URL

## Skills Learned

- Azure Storage Accounts
- Blob Storage
- Containers
- Private Access
- Shared Access Signatures (SAS)
- Secure File Sharing

## Outcome

Successfully secured a blob inside a private container and granted temporary access using a SAS URL.
