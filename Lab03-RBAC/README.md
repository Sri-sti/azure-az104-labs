# Lab 03 - Azure RBAC

## Objective
Learn and implement Azure Role-Based Access Control (RBAC) using Microsoft Entra ID and Resource Groups.

## Services Used

- Microsoft Entra ID
- Azure Resource Group
- Access Control (IAM)
- Azure RBAC

## Tasks Performed

1. Created Resource Group (RG-AZ104-LAB03)
2. Created a test user in Microsoft Entra ID
3. Assigned Reader role
4. Verified permissions
5. Changed role to Contributor
6. Verified updated permissions

## Roles Tested

- Reader
- Contributor

## Skills Learned

- RBAC
- IAM
- Entra ID
- Least Privilege Principle
- Role Assignments

## Outcome

Successfully configured and validated Azure RBAC permissions for a Microsoft Entra ID user.
