# Lab 01 - Azure Virtual Machine Deployment

## Objective

Deploy and manage an Ubuntu Virtual Machine in Microsoft Azure to gain hands-on experience with core AZ-104 administration concepts.

## Services Used

- Azure Resource Group
- Azure Virtual Network (VNet)
- Subnet
- Public IP Address
- Azure Virtual Machine (Ubuntu 24.04 LTS)
- Network Security Group (NSG)

## Environment Details

| Component | Name |
|------------|--------|
| Resource Group | RG-AZ104-LAB01 |
| Virtual Network | VNET-AZ104 |
| Virtual Machine | VM-AZ104 |
| Operating System | Ubuntu Server 24.04 LTS |
| Access Method | SSH |

## Tasks Performed

1. Created a Resource Group.
2. Created a Virtual Network and Subnet.
3. Deployed an Ubuntu Virtual Machine.
4. Configured a Public IP Address.
5. Configured Network Security Group rules.
6. Enabled SSH access.
7. Connected to the VM using SSH.
8. Executed basic Linux administration commands.
9. Stopped and removed resources to avoid unnecessary costs.

## Linux Commands Executed

```bash
hostname
whoami
pwd
ls
df -h
```

## Skills Learned

- Azure Resource Management
- Azure Virtual Machines
- Azure Networking
- Virtual Networks and Subnets
- Public IP Configuration
- SSH Connectivity
- Linux Administration Basics
- Cost Optimization and Resource Cleanup

## Outcome

Successfully deployed and managed an Ubuntu Virtual Machine in Azure, connected through SSH, verified system information using Linux commands, and cleaned up resources after testing.
